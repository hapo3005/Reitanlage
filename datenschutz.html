Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf werden technisch erforderliche Verbindungsdaten verarbeitet, damit die Website ausgeliefert und der sichere Betrieb gewährleistet werden kann. Nach Angaben von GitHub wird beim Besuch einer GitHub-Pages-Website insbesondere die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert.

Die Verarbeitung erfolgt, soweit sie in unserem Verantwortungsbereich liegt, auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Unser berechtigtes Interesse besteht in einer sicheren und zuverlässigen Bereitstellung dieser Website.
